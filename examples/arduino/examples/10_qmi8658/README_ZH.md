# QMI8658 加速度计

[English](README.md) | [简体中文](README_ZH.md)

## 功能

以 ±8 g 和 250 Hz 初始化 QMI8658 加速度计，并打印 X、Y、Z 加速度和两个中断电平。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

打开 `10_qmi8658.ino`，按仓库 README 选择 ESP32-P4 板卡配置，烧录后以 115200 波特率打开串口监视器。

## 预期现象

串口会报告检测到的 IMU 地址，并在移动开发板时更新加速度值。

## 常见问题

程序会依次尝试 `0x6B` 和 `0x6A`，期望设备 ID 为 `0x05`，I2C 出错后会重试。
