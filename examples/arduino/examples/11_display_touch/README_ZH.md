# 显示与触控

[English](README.md) | [简体中文](README_ZH.md)

## 功能

初始化 466 × 466 CO5300 MIPI-DSI 显示屏，依次显示红、绿、蓝画面，然后进入带清除按钮的 CST9217 触控绘图页面。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

打开 `11_display_touch.ino`，选择仓库 README 中的开发板配置后上传，并以 115200 波特率打开串口监视器。

## 预期现象

屏幕依次切换三种原色，随后显示白色触控页面。按住并拖动可连续画线，覆盖屏幕边缘；按 Clear 可以清除画布。

## 常见问题

请在 Arduino 开发板选项中启用 PSRAM。MIPI 显示依赖本仓库提供的共享显示库。
