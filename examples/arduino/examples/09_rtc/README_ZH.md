# PCF85063 RTC

[English](README.md) | [简体中文](README_ZH.md)

## 功能

每秒读取 PCF85063 的时间和状态，校验 BCD 日期并报告中断电平。程序不会写入 RTC 时间。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

打开 `09_rtc.ino`，按仓库 README 选择 ESP32-P4 板卡配置，烧录后以 115200 波特率打开串口监视器。

## 预期现象

串口会打印当前 RTC 日期、时间、振荡器停止状态和中断电平。

## 常见问题

BCD 数据无效或 I2C 读取失败时会打印错误，然后再次尝试读取。
