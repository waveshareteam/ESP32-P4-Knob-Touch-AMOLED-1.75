# 扬声器输出

[English](README.md) | [简体中文](README_ZH.md)

## 功能

初始化 ES8389 DAC 和 NS4150B 功放后，交替播放三秒 1 kHz 立体声测试音和三秒数字静音。

## 硬件需求

- 带音频转接板的 ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

在 Arduino IDE 中打开 `13_speaker_output.ino`，选择仓库 README 中的开发板配置后烧录，并以 115200 波特率打开串口监视器。

## 预期现象

串口会报告关键 ES8389 寄存器值。编解码器保持打开状态，扬声器会交替播放可听到的 1 kHz 测试音和数字静音。

## 常见问题

请确认音频转接板已连接。示例只在播放测试音时启用功放。
