# 按键

[English](README.md) | [简体中文](README_ZH.md)

## 功能

输出 BOOT 和 PWR 按键经过防抖后的按下与松开状态，并分别统计每个按键的按下次数。BOOT 为低电平有效，PWR 经板载反相后为高电平有效。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

用 Arduino IDE 打开 `02_buttons.ino`，选择仓库 README 所列的开发板配置，上传后以 115200 波特率打开串口监视器。

## 预期现象

串口监视器先输出两个按键的初始状态。按下或松开任一按键后，程序会在 30 ms 防抖后输出状态变化和对应的按下计数。

## 常见问题

BOOT 为低电平有效，程序使用内部上拉。PWR 经板载反相后为高电平有效；若启动后一直显示按下，请确认对应按键没有在启动时被按住。
