# SD 卡

[English](README.md) | [简体中文](README_ZH.md)

## 功能

通过 10 MHz 单线 SDMMC 挂载插入的 SD 卡，输出容量信息，校验一个新建临时文件，删除该文件后卸载 SD 卡。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板
- 兼容且已格式化为 FAT 的 microSD 卡

## 怎么运行

打开 `06_sd_card.ino`，选择 **ESP32P4 Dev Module**，并设置 32 MB Flash 与启用 PSRAM；烧录后以 115200 波特率打开串口监视器。

## 预期现象

串口会输出 10 MHz 单线配置、卡和文件系统容量，并报告写入、读回、删除校验以及卸载结果。

## 常见问题

本示例不会格式化 SD 卡，也不会改动已有文件。写入失败时会停止，不会删除日志中命名的临时文件；再次运行前请先检查 SD 卡。
