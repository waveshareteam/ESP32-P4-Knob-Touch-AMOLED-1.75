# 振动马达

[English](README.md) | [简体中文](README_ZH.md)

## 功能

通过串口命令驱动 DRV8837 振动马达执行一次最长 400 ms 的振动，并支持立即停止。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

用 Arduino IDE 打开 `08_motor_drive.ino`，采用仓库 README 中的开发板设置，上传后以 115200 波特率打开 UART 串口监视器。发送 `v` 开始一次振动，或发送 `s` 立即停止。

## 预期现象

发送 `v` 后马达开始振动，并在 400 ms 后自动停止。振动期间再次发送 `v` 不会延长超时时间。

## 常见问题

本示例仅控制板载振动马达，不提供调速或力反馈功能。
