# ESP32-P4-Knob-Touch-AMOLED-1.75 BSP

[English](README.md) | [简体中文](README_ZH.md)

This local board support package provides the display, touch, audio, storage, and power interfaces used by the Bluetooth A2DP Sink example. It targets `esp32p4` and also supplies board components referenced by other examples in this repository.
