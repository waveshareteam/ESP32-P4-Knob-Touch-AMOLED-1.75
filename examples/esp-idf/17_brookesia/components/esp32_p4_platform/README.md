# ESP32-P4 Knob Touch AMOLED 1.75 Compatibility BSP

[English](README.md) | [简体中文](README_ZH.md)

This local compatibility layer keeps the `esp32_p4_platform` component name expected by the ESP-Brookesia example while forwarding board support to the ESP32-P4-Knob-Touch-AMOLED-1.75 interfaces. It targets `esp32p4` and is specific to this example's component layout.
