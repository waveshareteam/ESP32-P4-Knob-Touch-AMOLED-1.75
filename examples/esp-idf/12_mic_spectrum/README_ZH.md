# 12 麦克风频谱

[English](README.md) | [简体中文](README_ZH.md)

## 功能

此示例从 ES7210 麦克风路径采集音频，并在 LVGL 屏幕上显示实时 FFT 频谱、RMS 电平和峰值电平。它禁用输出编解码器，并在独立任务中处理麦克风输入。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

在当前示例目录中，使用仓库 README 所列版本的 ESP-IDF 运行：

```bash
idf.py set-target esp32p4 build flash monitor
```

## 预期现象

屏幕会显示随附近声音变化的频谱条，以及 RMS、峰值、溢出次数和读取错误次数。音频初始化或采样失败时，状态行会指出失败阶段。

## 常见问题

此示例只采集麦克风输入，不会播放扬声器声音。队列溢出时会保留最新帧，因此可通过溢出计数判断显示路径是否负载过高。
