# 11 显示和触摸

[English](README.md) | [简体中文](README_ZH.md)

## 功能

此示例通过红、绿、蓝全屏阶段和随后的触摸绘图页面检查板载显示与触摸功能。绘图页面会在触摸位置添加圆点，并提供清除按钮。

## 硬件需求

- ESP32-P4-Knob-Touch-AMOLED-1.75 开发板

## 怎么运行

在当前示例目录中，使用仓库 README 所列版本的 ESP-IDF 运行：

```bash
idf.py set-target esp32p4 build flash monitor
```

## 预期现象

屏幕依次显示红、绿、蓝全屏，然后进入白色触摸页面。触摸页面会绘制黑色圆点；选择 **Clear** 后会清除圆点并重置计数。

## 常见问题

触摸颜色页面或按下 BOOT 按钮会提前切换到下一个颜色阶段。绘图页面保留数量受限的圆点，达到上限时会移除最早的圆点。
